* AI: [AI_EVAL_RESULTS.md](AI_EVAL_RESULTS.md) (the 60-prompt screening eval, run by the project), [AI_INVESTIGATOR.md](AI_INVESTIGATOR.md), [M6_*](M6_AGENT_ARCHITECTURE.md) reports.
* Storm atlas: [STORM_ATLAS_ARCHITECTURE.md](STORM_ATLAS_ARCHITECTURE.md), [STORM_ATLAS_DATA_PROVENANCE.md](STORM_ATLAS_DATA_PROVENANCE.md), [WEATHER_INTELLIGENCE.md](WEATHER_INTELLIGENCE.md).
